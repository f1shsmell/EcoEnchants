基于 EcoEnchants **2026.39**(含 Folia 支持)制作的全量简体中文汉化版本。保留原版全部功能与配置结构,将游戏内可见文本全部中文化,开箱即用,无需语言插件。

## 版本信息

| 项目 | 内容 |
|---|---|
| 基础版本 | EcoEnchants 2026.39 |
| 运行要求 | Paper 1.21.8+ / Folia,依赖 eco 2026.39 |
| 汉化范围 | 附魔名称与描述、/enchant 与 /enchantinfo 界面、命令消息、稀有度与适用物品名 |
| 兼容性 | EcoJobs / EcoPets / EcoSkills 联动附魔一并汉化 |

> 描述中的占位符(如 `%placeholder%`)、颜色代码与 `%ecoskills_*_name%` 引用原样保留,不影响任何数值与机制。所有译名均为配置文件中的普通文本,管理员可自行修改后 `/ecoenchants reload` 热重载。
